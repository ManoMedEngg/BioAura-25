# BioAura '25 🧬

**BioAura '25** is the official website for the National Level Technical Symposium organized by the Department of Biomedical Engineering. This platform serves as a hub for registrations, event details, and information about the various technical and non-technical challenges hosted during the symposium.

🔗 **Live Demo:** [https://manomedengg.github.io/BioAura-25/](https://manomedengg.github.io/BioAura-25/)

---

## 🚀 Features

- **Event Showcases:** Detailed descriptions and rules for events like Xenomedica (Paper Presentation), Medniche (Project Expo), and MedMystery (Quiz).
- **Online Registration:** A seamless flow for participants to register for multiple events.
- **Countdown Timer:** Real-time countdown to the event date.
- **Responsive Design:** Optimized for both desktop and mobile viewing.
- **Departmental Insights:** Information about the Biomedical Engineering department and its faculty.

---

## 🏆 Events Included

### Technical Events
* **Xenomedica:** Paper & Poster Presentation on futuristic medical technologies.
* **Medniche:** Project Expo showcasing innovative working models and prototypes.
* **MedMystery:** A technical quiz focused on medical case decoding and problem-solving.

### Non-Technical Events
* **Aura Connect:** A clue-based linking game.
* **Mind Blaster:** Puzzle-solving challenges.
* **Tik Tik Tik:** Rapid response and quick thinking rounds.
* **Surprise Event:** A mystery challenge revealed on the day of the symposium.
